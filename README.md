# Vulkan Video and graphics tooling for V

I build systems and graphics software in the
[V programming language](https://vlang.io), with a current focus on
hardware-accelerated video playback using Vulkan Video.

## Featured work

- [v_vulkan_video](https://github.com/antono2/v_vulkan_video) —
  hardware-accelerated H.264/MP4 video playback using Vulkan Video
- [vulkan](https://github.com/antono2/vulkan) —
  generated Vulkan and Vulkan Video bindings for V
- [v_vulkan_bindings](https://github.com/antono2/v_vulkan_bindings) —
  bindings generator and CI pipeline based on Khronos `vk.xml`
- [imgui](https://github.com/antono2/imgui) —
  Dear ImGui and ImPlot bindings with GLFW/Vulkan backends
- [glfw](https://github.com/antono2/glfw) —
  focused GLFW bindings for Vulkan applications in V
- [h264](https://github.com/antono2/h264) —
  H.264 bitstream parsing for Vulkan Video

My repositories cover the complete path from generated bindings and
bitstream parsing to windowing, user interfaces, and video playback.
